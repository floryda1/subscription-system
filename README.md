# Subscription Management System

Simple Python project for managing subscriptions, discounts, notifications and MRR.

## Features

* Basic, Pro and Enterprise plans
* Monthly and yearly billing
* Personal and business customers
* 10% yearly discount for Pro
* 20% discount for large business teams
* Email and SMS notifications
* MRR calculation

## Technologies

* Python
* OOP
* Dataclasses
* Enums
* ABC
* Factory Pattern
* Strategy Pattern

## How to Run

```bash
python main.py
```
